# Registro de la etapa 01

## Problema

Antes de diseñar el portfolio final era necesario decidir qué rutas, componentes y estados sostendrían la experiencia.

## Decisión

Se eligió una estructura multipágina simple. Cada vista tiene una responsabilidad clara y comparte layout, navegación, estado de API y pie. La estética de wireframe hace explícito que todavía no hay contenido definitivo.

## Pruebas previstas

- escritorio: 1440 × 900;
- tablet: 768 × 1024;
- móvil: 390 × 844;
- navegación con teclado;
- API normal y error controlado;
- cambio mapa/listado;
- filtros del archivo.

## Pendiente

Agregar contenido verificado, imágenes, identidad visual, casos extensos y fuente de datos definitiva en las siguientes iteraciones.
